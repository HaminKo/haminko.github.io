StarCraft: Brood War

SC Map Library In progress

A Windows desktop app for browsing, previewing and translating large collections of StarCraft: Brood War maps, with accurate minimaps, readable triggers and a map workshop.

Python · PySide6

SC Map Unfreeze Working

A companion to SC Map Library that lets it make working translated copies of abandoned Korean maps protected with euddraft’s freeze, keeping the original author’s credit. Kept private on purpose.

Python · reverse engineering

Falcon Paladin Replay Analysis In progress

An analysis of the community games on Falcon Paladin’s StarCraft: Brood War stream since 2017: which formats, maps and races get played, who plays most and who wins. Player ratings for team games and FFAs come later.

Python · pandas

SC Crash Monitor Working

A script that watches StarCraft: Remastered and, each time the game closes, tells a crash or hang from a normal exit. For each crash it saves the Windows event logs, Blizzard’s crash report and the game’s memory use from around that moment. It only reads logs and never changes the game.

PowerShell · Windows
